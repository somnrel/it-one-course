| Критерий | Selenium | Selenide |
|---|---|---|
| Объём бойлерплейта | Нужно писать больше кода: создавать драйвер, настраивать WebDriverWait и самостоятельно управлять ожиданиями | Кода меньше, т.к. selenide большую часть этого делает сам |
| Читаемость ассертов | нужно отдельно получить значение и потом его сравнить | Ассерты короче и понятнее |
| Изменения DOM | Если DOM изменился после того, как элемент уже был найден, можно получить StaleElementReferenceException | Selenide сам работает с элементом и при необходимости повторно ищет его в DOM и с готовностю элементов|
